# Travel Journal

Travel discovery by feeling rather than a long list of filters.

## Current stage

This is the initial interactive frontend prototype. It lets a visitor describe a trip in natural language and returns curated stay recommendations from a local demo dataset.

## Run locally

Open `index.html` in a modern browser.

## Roadmap

1. Move the prototype into a component-based web app.
2. Add real inventory, destinations, dates, and map search.
3. Add accounts, saved boards, and shareable itineraries.
4. Add a production search API and explainable preference matching.
5. Integrate an affiliate or booking provider.

## Notes

The current results are illustrative only: prices, availability, and stays are sample data rather than live inventory.
